# 时间线模板只是一个结果

《nobody》约 120 BPM、约七秒前奏的 33 秒结构，只是把这些音乐条件交给 plan.py 时得到的一种结果。历史 templates/opening.nobody.json 与 timeline.nobody.json 保留为语法参考，不能要求其他歌也有七秒前奏或四秒一乐句。原始歌长、窗口和是否插拍还会改变总时长。

现在的入口是 analyze_music → 角色 picks → plan.py。输出 plan.md 给用户看，四份 JSON 给渲染器；开头和结尾时长自动从全片扣除，不能重复追加一段已被正片占用的尾槽。

## 120 BPM、七秒前奏的一种结构

| 成片约时间 | 画面 | 音乐 |
|---|---|---|
| 0–7s | 人物、风格、大字与问题句 | 前奏重击与静音 |
| 7–15s | 最佳进场 → 过程英雄镜头 / 连续动作快切 | 两个乐句各自的铺垫、碎拍、呼吸 |
| 15–19s | 继续过程，九格回顾 | 中段呼吸不够两秒时向前借拍 |
| 19–23s | 过程高潮 | 最响乐句 |
| 23–27s | 擦除揭开 after → 终局九格 | 高潮后的第一句反转 |
| 27–31s | after 连贯动作 | 最后乐句的呼吸与余韵 |
| 31–33s | 爆炸聚字 / 可选关机 | 尾拍；关机也可另加一秒 |

这张表用于解释旧作品，不声称每首 120 BPM 歌都自动得到这些秒数。本轮同速度实歌默认三十秒窗口的自动结果是 6.96 秒开头、22.00 秒正片、1.04 秒聚字，九格在 12.96–14.96 秒及 24.96–26.96 秒。

## 另一首 86.13 BPM 实歌的自动排片

本机实测约 23.776 秒，没有长前奏；原始检测 172.27 BPM，选择半速 86.13 BPM。自动暂估 4/4，音轨有六八拍感，报告明确提示可试听后用 --meter 6/8 覆盖；这里如实列自动模式的结果，不附原音频或人物图。

| 成片时间 | 画面 | 音乐 |
|---|---|---|
| 0.00–1.76s | 五个简短事件，人物、强调色大字 | 短前奏压缩到 3–5 下 |
| 1.76–4.16s | 花絮中的真实进场 | 检测 drop / swell |
| 4.16–4.88s | 同一动作连续快切，至少半数 raw | chop |
| 4.88–6.92s | 安静连贯过程 | breath |
| 6.92–9.64s | 过程英雄镜头 | 高潮句 swell |
| 9.64–11.00s | 连续动作快切 | 高潮句 chop |
| 11.00–12.36s | 真实呼吸 | 高潮句 breath |
| 12.36–15.08s | 真实擦除揭开 after | 高潮后的第一句 |
| 15.08–15.76s | after 短快切 | chop |
| 15.76–17.84s | 九格逐格亮起，再翻成 after，之后全部在动 | 倒数第二句终局，向前借拍凑足两秒 |
| 17.84–20.52s | after 连贯镜头 | swell |
| 20.52–21.88s | after 连续动作快切 | chop |
| 21.88–22.60s | 安静画面 | breath |
| 22.60–23.76s | 点阵爆炸聚成 nobody. | 最后约两拍 |

25fps 下总长 594 帧 / 23.76 秒，末端比音频短约 0.016 秒，落在半帧量化范围。不同速度、短前奏和乐句长度直接改变结构，无需手动逐刀重排。制作建议先校对听感，尤其 drop、拍号和高潮，再确认 plan.md。
