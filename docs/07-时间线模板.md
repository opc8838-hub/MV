# 33 秒时间线模板

这是最终做法的结构模板，使用占位来源，不是原片的逐帧复刻。以 120 BPM 为基准，1 拍 0.5 秒，66 拍约 33 秒。真实曲目可能约 120.2 BPM 且前奏重击不均匀，应按分析结果修正；33.5 秒版本的插拍也不是所有歌曲都必须照搬。

| 成片拍 / 约秒 | 画面 | 音乐与剪法 |
|---|---|---|
| 0–14 / 0–7s | 动感排版开头 | opening 模板按 hits 重击编排，不硬套等距前奏 |
| 14–22 / 7–11s | 进场、抬头、推子，原片与热感短闪 | 长音连续 → 碎拍快切 → 热感呼吸 |
| 22–30 / 11–15s | 涂抹过程、点阵、连贯动作 | 同一个动作时钟前进，至少半数原片 |
| 30–36 / 15–18s | 工具英雄镜头 + 连续动作快切 | 跟踪框只叠在动作上，原片取景固定 |
| 36–40 / 18–20s | 九宫格 #1 逐格亮起，之后持续运动 | 前一拍揭开，后三拍看清九格 |
| 40–46 / 20–23s | 第二过程、字符脸、故障、离场 | 碎拍后收住、最后几帧压暗 |
| 46–50 / 23–25s | 擦除揭开与干净正脸 | 真实擦脸连续，不合成新脸 |
| 50–54 / 25–27s | 角度对比、吐气或轻笑 | 短刀之后给真实连续呼吸 |
| 54–58 / 27–29s | 九宫格 #2 按组变干净 | 每组翻面后继续真实运动 |
| 58–62 / 29–31s | 九格终局继续 | 不冻结，为粒子尾段选起始画面 |
| 62–66 / 31–33s | 爆炸聚字 + CRT 关机 | 独立 ending 尾段约 2 秒 |

`timeline.nobody.json` 只渲染正片本地 0–48 拍（24 秒），`opening` 约 7 秒，`ending` 约 2 秒，共约 33 秒。结尾用正片约 23.8 秒的九格画面取点，默认追加到正片后；无需再留一段重复的 2 秒占位尾巴。

模板只用两个素材别名组成九格以降低填表负担。正式制作按所选镜头增加九个不同别名，并为每格准备足够长的可用连续窗口。展示给用户的时间表必须加上开头时长，写成片时间；`timeline.json` 内的拍数是正片本地时间。

如使用真实 beatmap，指定正片的 `beat_origin`，并把开头 duration 设为音乐中这一拍的绝对秒数。结尾长度也应落在听感合适的完整拍上。换歌后重新试听、调整、渲染，不只是替换一个 BPM 数字。
