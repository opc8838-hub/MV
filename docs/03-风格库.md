# 风格库

所有处理输入真实 RGB 视频帧，输出同尺寸图像。`raw` 不调色；M3 自带颗粒和柔光，其他处理默认加轻暗角、颗粒及高光晕。`texture: false` 可在 Python 调用 `styles.apply` 时关闭这些表面质感。下表中的样张均在本地生成，不随仓库分发。

| 函数/名称 | 观感与使用位置 | 可调参数（Python apply） | 本地样张文件 |
|---|---|---|---|
| raw | 原片，作为真实感与呼吸基础 | 无 | S1-raw.png |
| thermal_silhouette | 黑底暖橙发光剪影，重击或整拍停留 | mask、phase（呼吸相位） | S2-thermal_silhouette.png |
| rainbow_thermal | 彩虹热谱，少量用在招牌快切 | mask | rainbow_thermal.png |
| dots3 | 纸底三档墨点，侧脸最易辨认 | step、growth、phase、mask | S3-dots3.png |
| one_bit | 米白与深藏蓝双色剪影，侧脸短闪 | Otsu 自动阈值 | S4-one_bit.png |
| negative | 灰度负片，作为快切短刀 | 无 | negative.png |
| ascii_face | 白底字符脸或黑底字符脸，崩溃段 | cell、light、mask | S6-ascii_face.png |
| mono_m3 | 银色电影黑白，红滤镜权重减轻皮肤疲态 | seed | S5-mono_m3.png |
| red_halftone | 红底暗红网点海报，用在重击大字后 | step、growth | red_halftone.png |
| pixel_stretch | 像素块与横向拉丝，2–3 帧短闪 | seed | pixel_stretch.png |
| glitch | 横向切片错位、RGB 分离，崩溃短闪 | seed | glitch.png |
| grid | 四宫格/九宫格同时运动，含逐格亮起和翻转 | n=2/3、gap；时间线见配置文档 | grid.png |

点阵档位半径为格距的 0.17 / 0.32 / 0.47；1080 宽默认格距 16px。M3 参数取自最后采用的黑白：RGB 权重 0.50/0.38/0.12，gamma 0.92，对比 1.14，黑位 6、白位 244，25% 保边柔化、8% 高光柔光和轻颗粒。

`style_sheet.py` 一次生成 S1–S6 六张单图与 `style-sheet.png`。其他风格可在私有脚本中调用：

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path('scripts').resolve()))
from common import Reader
from styles import apply
from PIL import Image
with Reader('work/input.mp4', start=1, count=1) as reader:
    Image.fromarray(apply(reader.read(), 'rainbow_thermal')).save('work/rainbow_thermal.png')
```

人物分割优先使用可用的 MediaPipe solutions；不支持时退回白墙阈值。复杂背景下必须先看样张，不能默认蒙版准确。热谱可以多色，但标题、框线等视觉强调仅用统一红色。
