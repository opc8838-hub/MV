# 拍摄指南

白墙前拍，固定机位，竖拍；前后对比穿同一件衣服、用相同光线和机位。避免自动曝光在动作中跳变，背景边缘不要放电视、门框或杂物。拍摄时稍留左右余量，后期统一做 9:16 固定裁切。

每类动作至少录 6 秒，动作前后各留一秒：正脸安静看镜头、分别向自己的左/右转头、走近镜头后站定、低头再抬头、点头、吐气、抿嘴笑。过程动作录完整，例如抹泡沫、刀划过脸颊、工具离开、擦脸；不要只拍一个姿势。

前置摄像头预览可能镜像，保存的视频可能不镜像。先举自己的左手录一小段，核对保存结果。沟通时明确「用户的左脸」，别混同「画面左侧」。固定裁切偏移不能修正镜像，要在选片前判断方向。

不要为了特写凑得过近；默认保留原人物比例。真实走近的动作可以使用，但不要后期再给脸放大。最终九宫格会持续数秒，每个候选需检查可用长度，避开离场、纸巾遮脸、手挡脸的部分。
