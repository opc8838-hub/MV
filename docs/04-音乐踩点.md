# 音乐踩点

```bash
python scripts/analyze_music.py work/song.wav --out work/music
```

也接受含音轨的视频。ffmpeg 先提取单声道分析音频；生成 `beatmap.json` 与 `structure.png`，不会修改原音乐。默认仅分析前 600 秒，可用 `--max-seconds` 调整。

| 字段 | 含义与限制 |
|---|---|
| bpm、beats | 估计速度与逐拍绝对秒数；不保证每个鼓点都检出 |
| bars、downbeat_phase | 用低频能量猜 4/4 小节首拍；不是拍号识别 |
| hits | onset 重击秒数与归一化强度，开头按此切画面 |
| silences | 低于相对能量阈值且至少 0.12 秒的空隙，不一定绝对静音 |
| phrases | 每 N 拍一组，默认 8 拍；估计 swell/chop/breath 倾向 |
| suggested_edit | 提议前 1/2 长音、中 1/4 碎拍、末 1/4 呼吸的画面分配；不是实际编曲转录 |

先试听，标出前奏、DROP、长音、最响碎拍和停顿，再修正 JSON。向用户讲「前奏约七秒，重击切画面；进主段之后，每四秒先让动作走，再闪几下，最后静下来」。音频分析不自动证明 DROP；开头结束时刻必须人工确定。

时间线用拍：例如 120 BPM 下 `start_beat:0, end_beat:4` 是两秒。读取真实 beatmap 后使用相邻拍之间线性细分，最终量化到最近的输出帧。`beat_origin` 指正片从原音乐哪一拍开始；正片内部从本段 0 秒起算，详见配置文档。开头 `hit` 是 hits 数组零起编号，直接映射原音乐绝对时刻。

延长音乐只能复制完整拍块。`assemble.py --insert-at 4 --insert-beats 2 --bpm 120` 会在最近拍插入约一秒定格，并先播放该点之后两拍的副本，再从该点恢复原音轨；画面后半同步后移。非均匀拍网格用 `--beatmap`，以实际拍差计算长度。插点、拍块长度和帧量化误差写在 `.assembly.json`。需要更自然的接缝时先试听，选波形与乐句结构合适的插点；脚本不自动做会移动拍点的交叉淡化。
