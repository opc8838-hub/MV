# 选片

```bash
python scripts/picks_gallery.py work/input.mp4 work/second.mp4 --out work/picks
```

默认每 1.6 秒一个候选，依次生成 `V1001`、`V1002` 等编号。打开输出中的 `index.html`，鼠标经过播放、点一下红框选中，再点取消；支持键盘 Enter/空格。复制编号后发给 AI；复制失败可直接复制顶部文本框。选择保存在该网页的本地存储中，不会上传。

长片先用 `--start 30 --end 60` 只做一个窗口，避免一次转码数千段。需要筛掉空镜时加 `--faces`：只保留开头、中间、末端三个采样点都检测到正脸的段落。转头、遮脸也可能被误删；重要动作使用手动分组。

`--groups work/groups.json` 可指定分组（路径相对 groups 文件）：

```json
[
  {"source":"input.mp4","prefix":"FACE","title":"变化前","start":0,"end":12,"skip":[[4,6]],"x_offset":0},
  {"source":"second.mp4","prefix":"CLEAN","title":"变化后","start":10,"end":22,"skip":[]}
]
```

跨越排除区间的候选也被跳过。prefix 需唯一，使用英文字母、数字、下划线或连字符。`--duration` 控制候选长度，`--step` 控制起点间隔。

输出 `picks.json` 是编号到路径、素材起点、x 偏移的映射。把所选项复制到时间线的 `sources` 时，**重新以时间线文件目录为基准调整路径**，别把相对选片目录的路径原样误用。候选长度不代表素材可无限延长；正式连贯镜头及九格需要逐段确认素材窗口。

选片网页、候选视频、路径映射均是私有生产数据，只留在 `work/`。公开模板仅使用占位别名。
