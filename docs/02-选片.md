# 选片与角色

```bash
python scripts/picks_gallery.py work/input.mp4 work/second.mp4 --start 0 --end 20 --out work/picks
```

默认每 1.6 秒一个候选。打开 `index.html`，勾选镜头、选择角色，可打 ★ hero，并单独允许定格/放大；这些授权默认关闭。原生控件支持键盘操作，鼠标经过播放，选择和标签保存在本地存储。点「复制我的选择（JSON）」后直接保存为私有 `picks.json`，复制失败可选顶部文本框复制。

| role | 含义 |
|---|---|
| before | 变化前 |
| process | 变化过程 |
| after | 变化后 |
| enter | 进场 / 走近镜头，DROP 首选 |
| profile | 侧脸 |
| hero | 想停留的英雄镜头；其他角色也可另勾 hero |
| detail | 细节，例如酒窝；不自动放大 |
| exit | 离场 / 擦除，用在反转揭开 |

导出的每项包括 id、path、start、duration、x_offset、role、hero、star、freeze、allow_zoom。完整来源路径仅存于本地导出，JSON 可以保存到任意私有目录；不要公开提交。网页旁的原始 `picks.json` 是全部候选的相对来源表，不是用户的最终选择，不要混淆。

默认可用时间只是候选的 1.6 秒。连贯英雄镜头和九宫格通常需要 4–6 秒，请播放原视频检查整段内容后，在「可用秒数」填写已确认的长度，或直接用 `--duration 5 --step 5` 生成较长候选。不能因为原视频很长就默认后续都可用；planner 不足时会报错。重叠候选按原文件时间统一去重。

长片用 --start/--end 限制窗口；`--faces` 只保留首/中/末都检测到正脸的候选，可能误删侧脸和遮挡动作。也可以用 `--groups work/groups.json`：

```json
[
  {"source":"input.mp4","prefix":"FACE","title":"变化前","start":0,"end":12,"skip":[[4,6]],"x_offset":0},
  {"source":"second.mp4","prefix":"CLEAN","title":"变化后","start":10,"end":22}
]
```

路径相对 groups 文件；prefix 唯一。跨越 skip 的候选跳过。`--step` 控制间距，x_offset 在整段保持固定。选片页、候选视频、路径、人物图和角色备注都留在 work/。
