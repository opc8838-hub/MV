# 剪辑语法

前奏每一下重击换一个视觉事件：暗场光标、真实脸、大字纸页、热感扫描、三档点阵、M3 海报、四宫格、红底问号、切条揭开 DROP。文字可动，人物画面保持真实运动。`opening.py` 从配置读取重击编号；纸张底与结尾统一。

连续动作快切不是换十个姿势。选一段 1–2 秒连续动作，切成 3–6 帧的小刀；第 n 刀继承上一刀之后的素材时刻。`chop` 一次打开同一个 Reader，从不在换风格时重新 seek。处理序列至少半数原片，原片/点阵/原片/负片/原片/M3 等交替；段落之间换动作才是大剪辑点。快切可落在八分/十六分音符上，但需避免量化后成为 0 帧。

英雄镜头给动作 0.8–1.6 秒或更久，不切。固定裁切，跟踪框用模板匹配在真实帧上移动；刀片放大镜只针对工具，需先给准初始框并检查跟踪。低对比或遮挡时模板匹配会漂移，不能代替视觉复核。默认不做脸部放大镜。

侧脸适合 2–4 帧短刀。左右可交替不同片段；每一段素材自己的时钟要前进，切换在明晰动作处。需要不同镜头交替时写多个短 `clip` 段，分别递增各来源 offset；单一 `chop` 表达一个连续来源动作。

四宫格常用于开头同一动作四种风格；九宫格用于过程回顾与终局。所有格子每个输出帧都读新源帧，未显示的格子时钟也前进。`reveal` 按中心螺旋逐格亮起，`flip` 每组翻成另一组运动画面；翻完以后继续留时间让用户看清九格都在动。它们是同一时钟下的硬切翻面，不做虚假的三维脸变形。

擦除揭开依靠真实擦脸动作，保持比例不跳。`wipe:true` 只叠一条移动扫描线，不合成前后脸；先选一段本来就从遮挡到露出的素材。

定格仅用户点名时使用：`freeze` 配置 `authorized:true`，固定画面加红框，不推近。插入 N 拍用 assemble 同步延长音轨。普通呼吸仍应播真实连贯镜头，不能用 freeze 偷代替。

结尾从九格或一帧真实画面取点：短暂点阵化 → 向外爆炸 → 加速撞成可配置的词 → 熔成实字 → 垂直压成电视亮线 → 横向缩成点 → 黑场。这里是明确的图形动画例外，人物镜头仍不生成、不补帧。`ending.py` 输出独立尾段；拼接时别把占位结尾重复保留。
